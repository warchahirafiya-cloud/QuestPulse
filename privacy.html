سياسة الخصوصية

توضح هذه الصفحة بصورة أولية كيفية التعامل مع البيانات عند زيارة QuestPulse، وهو دليل معلوماتي لاكتشاف منصات المكافآت والمهام الرقمية والعروض. لا تتضمن النسخة الحالية حسابات مستخدمين أو نماذج تسجيل أو نماذج دفع داخل الموقع.

تنبيه: هذه مسودة وليست إشعاراً قانونياً نهائياً. يجب استكمال هوية الجهة المشغلة ووسيلة التواصل، والتحقق من إعدادات التحليلات والكوكيز وروابط الإحالة ومزودي الاستضافة قبل اعتمادها.

1. البيانات التي تقدمها

لا تطلب صفحات الموقع الحالية إنشاء حساب أو إدخال بيانات دفع. لا ترسل كلمات المرور أو رموز التحقق أو بيانات الهوية أو المعلومات المالية عبر الموقع أو إلى أي جهة غير موثوقة.

2. بيانات التشغيل والاستضافة

قد تعالج خدمات الاستضافة والبنية التحتية بيانات تقنية مثل عنوان IP ووقت الطلب ونوع المتصفح ومعلومات الجهاز لأغراض تشغيل الموقع والحماية. تعتمد تفاصيل المعالجة والاحتفاظ على إعدادات مزودي الخدمة وسياساتهم، ويجب توثيقها قبل نشر النسخة النهائية من هذه السياسة.

3. التخزين المحلي

قد يستخدم المتصفح التخزين المؤقت وميزة Service Worker لتحميل صفحات الموقع وتحسين الأداء والعمل دون اتصال. يمكن إدارة بيانات الموقع من إعدادات المتصفح.

4. الروابط الخارجية وبرامج الإحالة

قد يتضمن الدليل روابط إلى مواقع وخدمات خارجية، وقد تُستخدم روابط إحالة عند الإفصاح عن ذلك بوضوح. عند الانتقال إلى موقع خارجي، تخضع بياناتك لسياسة ذلك الموقع وشروطه. يجب التحقق من أي أدوات تتبع أو ملفات تعريف ارتباط مرتبطة بهذه الروابط قبل اعتماد السياسة نهائياً.

5. التحليلات وملفات تعريف الارتباط

لا تفترض هذه المسودة استخدام أداة تحليلات أو إعلانات بعينها. يجب مراجعة إعدادات النطاق والاستضافة وأي خدمات طرف ثالث لتحديد ما إذا كانت ملفات تعريف الارتباط أو أدوات القياس مستخدمة، ثم تحديث هذا القسم وفق الواقع.

6. حقوق الزائر والتواصل

يجب إضافة بيانات الجهة المسؤولة ووسيلة تواصل فعالة، وتوضيح طريقة طلب الاستفسارات أو التعامل مع البيانات وفق المتطلبات القانونية المنطبقة، قبل اعتماد السياسة النهائية.
