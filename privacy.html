سياسة الخصوصية

يوضح هذا الإشعار بصورة أولية كيفية تعامل النسخة الحالية من QuestPulse مع المعلومات عند زيارة الموقع. يجب مراجعته وتحديثه قبل الإطلاق العام، خصوصاً بعد تحديد مشغّل الموقع ومزوّدي الاستضافة والتحليلات وأي خدمات خارجية.

تنبيه: هذه مسودة معلوماتية وليست سياسة خصوصية نهائية أو استشارة قانونية. لا تفترض أن الموقع لا يعالج أي بيانات؛ قد تعالج خدمات الاستضافة والبنية التحتية بيانات تقنية وفق سياساتها الخاصة.

1. ما الذي يفعله الموقع حالياً؟

  • يعرض صفحات معلوماتية ثابتة وسجل فرص بصيغة JSON يتم جلبه لعرض الحالة والمعلومات.
  • قد يسجل متصفحك ملفات الموقع مؤقتاً عبر التخزين المؤقت وميزة العمل دون اتصال (Service Worker).
  • لا تتضمن النسخة الحالية، بحسب الوظائف المنشورة، إنشاء حساب مستخدم أو نموذج إرسال بيانات شخصية أو نظام دفع داخل الموقع.
  • لا يوجد في النسخة الحالية رصيد QP قابل للاسترداد أو سجل مكافآت حقيقي؛ أي عداد ظاهر هو عنصر واجهة فقط.

2. سجلات الخادم والجهات الخارجية

قد يتلقى مزود الاستضافة أو GitHub بيانات تقنية مثل عنوان IP ووقت الطلب ونوع المتصفح ومعلومات الجهاز لأغراض تشغيل الخدمة والحماية، وفق إعداداته وسياساته. لا نملك من داخل صفحات الموقع وحدها تفاصيل مدد الاحتفاظ أو المعالجة لدى المزود.

إذا أضيفت لاحقاً أدوات تحليلات أو خطوط أو صور أو فيديو أو روابط خارجية، فيجب إدراج أسماء الجهات وأنواع البيانات وأغراضها قبل تفعيلها.

3. ملفات الارتباط والتخزين المحلي

لا تعلن النسخة الحالية عن استخدام ملفات تعريف ارتباط إعلانية أو تتبع سلوكي خاص بـ QuestPulse. قد يستخدم المتصفح التخزين المؤقت وبيانات Service Worker لتقديم الملفات وتحسين التحميل والعمل دون اتصال. إعدادات المتصفح تتيح عادة إدارة بيانات المواقع وحذفها.

4. الروابط الخارجية

قد تشير صفحات مستقبلية إلى مواقع أو خدمات لا نديرها. يخضع استخدام تلك المواقع لسياساتها وشروطها المستقلة. تحقق من النطاق قبل إدخال أي بيانات، ولا تشارك عبارة الاسترداد أو المفتاح الخاص.

5. الأطفال والبيانات الحساسة

لا تطلب من خلال النسخة الحالية إرسال بيانات الهوية أو المعلومات المالية الخاصة أو بيانات الدخول. لا ترفع أو ترسل مفاتيح المحافظ أو عبارات الاسترداد أو رموز المصادقة إلى QuestPulse أو إلى أي جهة تدعي تمثيله.

6. حقوقك وطلبات الخصوصية

قبل النشر النهائي يجب تحديد جهة مسؤولة ووسيلة اتصال مخصصة لطلبات الوصول أو التصحيح أو الحذف أو الاعتراض، وفق القانون المنطبق. لم تُحدد في هذه المسودة بيانات اتصال؛ لا تستخدم عنواناً افتراضياً أو غير مراقب.

7. التعديلات

قد يتغير هذا الإشعار عند إضافة ميزات أو مزودي خدمة. يجب تحديث تاريخ النسخة وشرح التغييرات الجوهرية بوضوح.

8. ما قبل الإطلاق

يلزم استكمال اسم الجهة المشغلة ووسيلة الاتصال ومزودي الاستضافة الفعليين ومدة الاحتفاظ وسند المعالجة ونطاق الجمهور وأي نقل بيانات دولي، ثم مراجعة النص قانونياً قبل اعتماده.
