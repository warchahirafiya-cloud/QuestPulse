# أرشيف QuestPulse — المواد السابقة

هذا المجلد يحفظ المواد التي أُزيلت من النسخة التشغيلية الحالية للموقع.

## المحتويات
- `opportunities.json`: نسخة بيانات السجل السابق.
- `PROJECT_DOSSIER.md`: ملف تعريف المشروع السابق وخطته.
- `EDITORIAL_POLICY.md`: السياسة التحريرية السابقة.
- `OPPORTUNITY_REVIEW_WORKFLOW.md`: سير مراجعة السجلات السابق.
- `SAFE_PUBLISHING.md`: تعليمات النشر السابقة.
- `legacy/index.html` و`legacy/guide.html`: نسختان تاريخيتان من الواجهة والدليل قبل التنظيف.

## الحالة
- هذه الملفات محفوظة للرجوع التاريخي فقط، وليست جزءاً من الموقع النشط.
- أزيلت من الواجهة الحالية أقسام الفرص والسجلات ولوحة التحرير وواجهات الخدمة المرتبطة بها.
- لا توجد روابط مشاركة أو دعوات أو تعليمات تشغيل مرتبطة بهذه المواد في الموقع الحالي.
- إذا تقرر تطوير هذه الفئة مستقبلاً، فسيكون ذلك مشروعاً برمجياً جديداً ومراجعة مستقلة قبل النشر.
